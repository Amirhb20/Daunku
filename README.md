# 🌱 Daunku

A modern and responsive plant pot e-commerce website built with **HTML, CSS, and JavaScript**.

Daunku is a front-end e-commerce project designed to provide a clean, modern, and user-friendly experience for discovering and exploring plant pots.

## ✨ Features

* 🪴 Modern and clean user interface
* 📱 Responsive design for desktop, tablet, and mobile
* 🛍️ Product showcase
* 🎨 Custom CSS styling
* ✨ CSS animations and visual effects
* ⚡ JavaScript interactions
* 📐 Responsive layout

## 🛠️ Technologies

* **HTML5** — Semantic page structure
* **CSS3** — Styling, layout, animations, and responsive design
* **JavaScript** — Interactive functionality and DOM manipulation

## 🚀 Getting Started

### Clone the repository

```bash
git clone <repository-url>
```

### Open the project

```bash
cd daunku
```

Then open `index.html` in your browser.

You can also use **Live Server** in VS Code for a better development experience.
